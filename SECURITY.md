# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.2.x   | :white_check_mark: |
| < 1.2   | :x:                |

## Reporting a Vulnerability

Do not open a public issue. Send a private report to shleyger@gmail.com
or use GitHub Security Advisories on this repository.

Expect a first reply within 7 days. If the report is accepted, the fix
ships in a new patch version. If it is declined, the reply explains why.
